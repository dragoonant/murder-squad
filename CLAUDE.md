# Murder Squad — agent orientation

Fan-made 3D browser game of Warhammer 40,000: Kill Team (2024 edition mechanics, 1:1), MGSD figures, player vs AI. Read in this order, nothing else up front: `HANDOFF.md` (current state, next steps) → `STATUS.md` (what exists) → `PLAN.md` (decisions, milestones) → `KICKOFF.md` (owner's answers and reasoning) → the `docs/spec/` sections a task names. Cross-project lessons live in `docs/knowledge-base/README.md`; read only the section a task needs.

## Owner priorities
- **Playable first.** Something the owner can open on Pages and play beats test coverage. Every stage ends in something visible (screenshot).
- **Fidelity is the product.** Mechanics 1:1 from the current edition (sources in `docs/sources/`, gitignored). Never tune printed numbers. Ambiguities never block: append `RULING: <rule> | <what we did> | <why>` to `docs/needs-rules-check.md` with a status word (Confirmed, Corrected, Unsourced, Fan-source) and keep going.
- **No intervention run.** Make the logical choice, record it in `PLAN.md` (decisions table) with its reasoning, and continue. Check-ins are 10 lines or fewer with a screenshot. Stop only for passwords, payment, account creation or a real blocker.

## Token rules (metered plan; not optional)
- The main loop never reads whole source files or hand-writes bulk code. It writes agent briefs with exact file lists, reads structured results and diffs, and runs the gates.
- Implementation and data entry run on Sonnet agents. Spec work and verification of rules-dense code (shoot/fight sequence, weapon rules, team data) run on the session model. Agents return ≤300-token summaries.
- One or two agents per milestone, one stage at a time, commit and push after each stage. Agents never run `npm install`, `git commit` or `git push` unless told; never edit `STATUS.md`, `package.json` or files outside their list; run long commands in the foreground with a time cap; never `taskkill` by image name.
- Gates: `npm run typecheck`, `npm test`, `npm run validate:data`, `npm run sim -- --games 50`, `npm run bench:ai`, one Playwright game. Lean: about 10 focused tests per stage, no review loops except the attack sequence and team data.

## Conventions
- 1 world unit = 1 inch, y up, 30" x 22" killzone centred at the origin; `+Z` is the figure's front.
- Engine contracts are frozen after M2: `src/engine/{types,actions,events,hooks,rng,decider,view,index}.ts`. Any change is additive and gets a row in `docs/spec/00-architecture.md` §change log.
- Exactly one `PendingDecision` at a time; `legalActions` is never empty for an open decision; illegal input returns a `Rejection`, never throws; deciders see only `view(state, seat)`; the engine owns every number the UI shows (`query.*`).
- Engine tests are named by checklist ID from `docs/spec/12-rules-test-checklist.md` (e.g. `it('SHOOT-004 ...')`).
- Data is declarative JSON validated by ajv; `{"code": "<hook>"}` escape hatches are registered in `src/engine/code-hooks.ts`, and every code hook has a test proving it fires in a real game.
- Client: `src/client/store/game.ts` is the only caller of `step`; presentation runs through the director and presented-state cursor; the bot waits for presentation idle; no native `title=` tooltips (shared `Tooltip.tsx`); prompts name what they decide and show engine odds.
- Figures: body GLB per operative archetype with named sockets; weapons and equipment are attachment GLBs chosen by the operative's loadout (rules-legal options only); procedural stand-in until the GLB exists. GLB contract: origin at base centre, y up, 1 unit = 1 inch, front `+Z`, pre-scaled upstream.
- Audio: generated by the local Audio Studio (http://localhost:7890) through `tools/gen-audio.ts` from `tools/audio-manifest.json`; weapon-flavour map first; measured trims; audition page `public/sounds.html`. No ElevenLabs.
- Commit messages: `M<n>: <what>` + blank line + `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Pushing to `main` after each stage is pre-approved; Pages deploys from `main`.

## IP and privacy
Mechanics are ported 1:1; team, operative, weapon, ploy and equipment names may match; all prose (ability text, lore, UI copy) is our own wording, never Games Workshop text. No GW art, icons or logos. `docs/sources/` (PDFs, extracted text, Wahapedia dumps) is gitignored and never published. Figures are original MGSD designs. Credit the owner as **evilgouki**; never write the owner's real name or home path into any file; grep for both before every commit.

## Edition leak list (paste into every rules prompt)
Not 2021 Kill Team (shape distances, Overwatch action, 2 APL everywhere, parry), not 40k 10th (wound rolls, AP vs armour, coherency, battle-shock, Command phase), not Into the Dark close-quarters rules unless the killzone is Gallowdark. Inches only; three defence dice; cover save; obscured discards one success; counteract; crit op + tac op + kill op scoring.
